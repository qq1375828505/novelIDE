═══════════════════════════════════════════════════════════════════════════
                       交 互 数 据 流
═══════════════════════════════════════════════════════════════════════════
 用户输入 → AiChatPage._sendMessage()
    ↓
 模糊需求检测 → 有 → 弹选择卡片（30秒冷却）
    ↓
 发送给 WorkspaceAgent.chat()
    ↓
    ├─ AI直接回复 → 返回给用户
    │
    ├─ AI调用工具 → 执行 → 结果回传 → 继续迭代(最多5轮)
    │   ├─ 读作品/资料 → 从文件系统读取 → 结果给AI
    │   ├─ 写入资料库 → MaterialRepository → 存JSON
    │   ├─ 写章节 → SQLite + .md文件
    │   ├─ 联网搜索 → DuckDuckGo API → 结果
    │   │
    │   └─ delegate_to_sub_agent → 独立AiService调用
    │        ├─ 模糊匹配子Agent（中文名/ID/关键词）
    │        ├─ 系统提示 = 子Agent预设 + 迭代指令
    │        ├─ 最多3轮推敲（收敛检测）
    │        └─ 返回结果 → 主Agent整合 → 呈现给用户
    │
    └─ AI最终回复 → 显示给用户
        ↓
        交互完成后 → _extractAndSaveMemory() → MemoryPipeline 自动提取记忆
